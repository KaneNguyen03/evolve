# 💡 Peace brainstorm log

Raw ideas live here before they're ready to become [RFCs](../rfcs/). Rough is fine. In Peace, a half-formed idea is a mutation: most won't survive, and that's how the good ones are found.

## How it works

- One file per session: `YYYY-MM-DD-topic.md`, created by the `peace-brainstorm` Claude skill or by hand.
- Each idea gets a status: 🌱 `seed` (raw), 🌿 `growing` (worth exploring), 📜 `rfc` (moved into an RFC, linked), 🦴 `fossil` (dropped, with the reason).
- Ideas that graduate link to their RFC. Dropped ideas stay, with why they were dropped.
